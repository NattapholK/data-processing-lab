# OOP Data Processing (Commit 3)

## Lab Overview
This lab refactors a procedural data processing script into an Object-Oriented Programming (OOP) design in Python. By encapsulating CSV loading and table manipulation behaviors into reusable classes (`DataLoader` and `Table`), the codebase becomes cleaner, modular, and easier to maintain and extend.
